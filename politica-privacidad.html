Política de Privacidad de FESTIGOL

Última actualización: 22 de septiembre de 2026

FESTIGOL es una plataforma para la gestión y consulta de torneos deportivos.

1. Información que recopilamos

FESTIGOL puede manejar nombres, datos de contacto, información de equipos y jugadores, fotografías, resultados, estadísticas y demás información necesaria para administrar los torneos.

2. Uso de la información

La información se utiliza para registrar equipos y jugadores, administrar partidos, generar tablas, estadísticas, planillas, carnés y facilitar las comunicaciones relacionadas con los torneos.

3. WhatsApp

Cuando se utilice el servicio de WhatsApp de FESTIGOL, los mensajes recibidos podrán procesarse para responder consultas relacionadas con torneos, equipos, partidos y estadísticas.

4. Información pública

Los nombres deportivos, equipos, resultados, posiciones, goles, tarjetas y estadísticas podrán mostrarse públicamente cuando el administrador del torneo configure dichas funciones.

5. Protección de datos

FESTIGOL aplica medidas razonables para proteger la información contra acceso, modificación, pérdida o divulgación no autorizada.

6. Eliminación o modificación de datos

Para solicitar la actualización, corrección o eliminación de datos personales, puede comunicarse con FESTIGOL mediante el correo indicado a continuación.
